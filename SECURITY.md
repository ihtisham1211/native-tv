# Security policy

How the server protects itself, what it exposes and how to harden it is in
[docs/administration/security.md](docs/administration/security.md).

## Reporting a vulnerability

Report a vulnerability privately, through GitHub's
[private vulnerability reporting](https://github.com/ihtisham1211/native-tv/security/advisories/new)
for this repository. Do not open a public issue for it. A report that names the
affected version, the TV and webOS version and the steps to reproduce is the
quickest to act on.

Fixes go into the latest release; older releases are not patched.
