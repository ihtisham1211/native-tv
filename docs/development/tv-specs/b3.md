# LG OLED65B3PUA (2023 — webOS 10)

Hardware profile and low-level data gathered from root shell access on an LG OLED65B3PUA running webOS 10.3.2 (LG's webOS 25).

---

## System Overview

| Detail | Value |
|---|---|
| **Model** | OLED65B3PUA (panel module LGD, `eBackLight=oled`, `eModelToolType=B3` on the kernel command line) |
| **Firmware** | 33.31.75 |
| **webOS** | 10.3.2-33 (codename `ponytail-papikonda`), image `lib32-starfish-global-secured`, built 22 August 2026 |
| **Kernel** | Linux 5.4.268-294.24.papikonda.2 (aarch64, SMP PREEMPT) |
| **Userspace** | 32-bit ARM (`node` is an ELF32 binary) |
| **SoC** | Alpha 7 Gen 6, chip ID `K8HPPA0` (from the boot command line) |
| **Root filesystem** | `/dev/mmcblk0p27`, squashfs, read-only |

---

## CPU

| Detail | Value |
|---|---|
| **Architecture** | ARMv8.2-A — Cortex-A55 (CPU part `0xd05`) |
| **Cores** | 4, all online |
| **Frequency steps** | 1156 MHz (single fixed OPP) |
| **Governor** | `schedutil` (available: userspace, performance, schedutil) |
| **Scaling driver** | `realtek_cpufreq` |
| **BogoMIPS** | 54.00 per core |
| **Features** | fp asimd evtstrm aes pmull sha1 sha2 crc32 atomics fphp asimdhp cpuid asimdrdm lrcpc dcpop asimddp |

The load average stays near 32 booted or not: 31 of LG's driver threads sit in
uninterruptible sleep, which Linux counts as load. With Netflix playing the CPU
was 26% busy at that load.

## Cold start timing

How the first minute goes on this TV, with Quick Start+ off, is in
[TV-RESEARCH.md](../TV-RESEARCH.md#what-starts-the-boot-hook-and-when-b3-webos-1032):
`core-boot-done` at about 19 s, the input in front at 22 s, the Homebrew
Channel's `startup.sh` at about 41 s and the Native Tv server listening at
about 54-63 s. The start-up splash that fills the gap from about 23 s is in
[the same file](../TV-RESEARCH.md#a-splash-during-the-cold-start-b3-webos-1032).
