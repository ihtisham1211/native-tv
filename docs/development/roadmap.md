# Roadmap

What the TV app is still missing next to Google TV, whose layout it follows. The web dashboard is not affected.

## Editing apps

- **Home.** There is no edit mode: apps cannot be reordered or removed from the screen. Google TV's edit mode is the model.
- **Apps.** The Apps screen has the same gap: no reordering and no deleting of an app from the list, with the same edit mode as Home.

## Settings

- The Settings page has no tabs and no quick-settings icon, both of which Google TV's Settings has.
