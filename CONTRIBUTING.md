# Contributing

Changes are welcome as pull requests. How to build, test and describe a change is
in [docs/development/contributing.md](docs/development/contributing.md); the layout of the code is in the
[code map](CLAUDE.md#code-map) and [native-tv/ARCHITECTURE.md](native-tv/ARCHITECTURE.md).

Before opening a pull request:

* Run the checks listed in [Testing and CI](docs/development/testing.md).
* Update the docs that describe the change.
* Fill in the pull request template, including its **Testing** section: the TV and
  webOS version tried, what was done and seen, and what was not tested.

Bugs and ideas go in the [issues](https://github.com/ihtisham1211/native-tv/issues).
Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
